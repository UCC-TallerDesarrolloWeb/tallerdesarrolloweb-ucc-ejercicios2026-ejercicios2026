# Unidad 2: Fundamentos de HTML5 y CSS3

## Filminas

- `U2_HTML_avanzado.html`: HTML avanzado, accesibilidad, formularios, multimedia, canvas y buenas practicas.
- `U2_CSS.html`: CSS, formas de aplicar estilos, selectores, propiedades tipograficas, descendientes, pseudo clases, modelo de cajas, fondos y CV.
- `U2_CSS_avanzado.html`: CSS avanzado, position, float, flexbox, grid, grid-areas, transitions, reset CSS, viewport y responsive.
- `U2_prototipado.html`: arquitectura de informacion, proceso de disenio de interfaz, sketch, wireframe, mockup, prototipo y evaluacion.
- `U2_interfazUsuario.html`: principios de diseño de interfaz, mensajes del sistema, usabilidad y tecnicas de evaluacion.

## Carpetas de ejercicios

- `1-HTML`: ejercicios de HTML.
- `2-CSS`: ejercicios de CSS. Incluye CV, columnas, backgrounds, productos con grid/grid-areas/transitions e Instagram responsive.
- `3-Prototipado`: entregables de arquitectura de informacion y prototipado para el proyecto de una pagina web de restaurante.

## Guia rapida

- `RESUMEN_HTML_AVANZADO.md`: resumen ordenado de la filmina `U2_HTML_avanzado.html`.
- `RESUMEN_CSS_AVANZADO.md`: resumen de position, float, flexbox, grid, transitions, viewport y responsive.
- `simulador_parcialito_html.html`: formulario autocorregible para practicar HTML con las preguntas del simulacro y refuerzos de clase.
