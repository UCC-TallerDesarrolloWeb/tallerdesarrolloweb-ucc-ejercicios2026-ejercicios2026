# Unidad 1: Introduccion y Herramientas de Desarrollo

## Filminas principales

- `U1_herramientas.html`: herramientas de desarrollo, IDEs, VCS, repositorios, Jira, documentacion, CI/CD, testing, debugging, dependencias, contenedores, monitoreo, APIs y otras herramientas.
- `U1_git.html`: Git basico, configuracion, estados, comandos principales, GitHub, ramas, merge, fork, pull request, code review y GitHub Classroom.
- `U1_git_avanzado.html`: repaso de Git, reset, stash, checkout a commits, amend, revert, rebase, autenticacion segura, README, Markdown, `.gitignore` y configuraciones de GitHub.

## Consignas de Unidad 1

- Readme.md: agregar secciones de autor y contenido, autores en items, apellidos en negrita, link del aula virtual, tabla de contacto y emoji.
- `.gitignore`: crear el archivo, incluir la carpeta a ignorar y subir los cambios al repositorio remoto.

## Para el parcialito

Usa `GUIA_PARCIALITO_U1_MEJORADA.md` como guia principal para multiple choice. Esta ordena lo que toman por definiciones, diferencias, ejemplos de herramientas y trampas comunes.
